# AutoGEN
O AutoGEN é um web app que auxilia na compra de carros usados. Ele cruza dados da Tabela FIPE com anúncios reais via web scraping da OLX (Python/Flask) e usa a IA do Google Gemini para analisar o custo-benefício, listar pontos de atenção e sugerir alternativas. Inclui interface moderna e rodízio de chaves API.
